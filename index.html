FAQ

Pertanyaan Umum

Bagaimana cara melakukan order? +

Pilih layanan, masukkan detail order, data akun, nomor WhatsApp, admin, dan metode pembayaran. Setelah itu tekan tombol WhatsApp untuk mengirim detail order ke admin.

Apakah harga sudah termasuk semua biaya? +

Harga pada katalog merupakan harga dasar layanan. Admin akan melakukan pengecekan akhir sebelum pembayaran dikonfirmasi.

Apakah data akun disimpan? +

Website ini tidak memiliki database akun. Data order dibuat di browser lalu dikirim kepada admin melalui WhatsApp. Jangan menggunakan password yang sama dengan akun penting lainnya.

Apakah bisa request hero? +

Bisa. Tulis hero yang wajib digunakan atau hero yang tidak boleh digunakan pada kolom catatan atau request hero.
